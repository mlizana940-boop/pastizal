# Responsabilidades del equipo

El equipo está conformado por tres integrantes. La sección 4 del PDF permite equipos de tres o cuatro. Los apartados 11 y 16 mencionan cuatro integrantes, por lo que se recomienda confirmar con el docente si esa redacción se aplica literalmente al equipo.

| Integrante | Funciones asignadas | Evidencia para la presentación |
|---|---|---|
| Tú: panel, backend y Firestore | Mantener la API Express y sus validaciones; desarrollar el acceso y las vistas de administración; implementar el CRUD de cabañas y la gestión de estados de reserva; revisar el modelo de datos y la integración con Firestore; explicar la verificación del administrador. | Demostrar inicio de sesión administrativo, creación y edición de una cabaña, listado de solicitudes y cambio de estado. |
| Compañero: cliente | Implementar la página pública; consulta y filtros de disponibilidad; formulario de solicitud; mensajes de validación; integración con la API pública. | Demostrar la consulta del catálogo y el recorrido del cliente hasta crear una solicitud. |
| Compañero: Azure | Desplegar la aplicación en la máquina virtual acordada; configurar variables y secretos en el servidor; verificar acceso y funcionamiento; registrar los servicios y recursos Azure reales. | Mostrar la URL, explicar los recursos Azure usados y presentar evidencias del despliegue y pruebas. |

Los nombres propios se pueden añadir al reemplazar los rótulos de rol. Aunque las tareas están repartidas, los tres integrantes deben poder explicar el diagrama completo, el flujo de una reserva, las decisiones de seguridad, las ventajas y las limitaciones.
